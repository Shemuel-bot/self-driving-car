# Self-Driving Car Simulation

A JavaScript-based simulation of a self-driving car navigating a road with sensors and neural network controls.

## Features

- Car physics and movement
- Sensor system for obstacle detection
- Neural network for autonomous driving
- Road generation
- Real-time visualization

## How to Run

1. Open `index.html` in a web browser
2. The simulation will start automatically

## Files

- `index.html` - Main HTML page
- `main.js` - Entry point and main loop
- `car.js` - Car class and physics
- `carInstantiator.js` - Car instantiation logic
- `controls.js` - User controls
- `network.js` - Neural network implementation
- `road.js` - Road generation and rendering
- `sensor.js` - Sensor system
- `utils.js` - Utility functions
- `visualizer.js` - Visualization components
- `style.css` - Styling

## Technologies

- JavaScript (ES6+)
- HTML5 Canvas
- CSS3
